# Мир пряжи — приложение учёта и продаж

Python 3.10+, Tkinter, SQLite, Pillow.

## Запуск
```bash
python -m pip install -r requirements.txt
python main.py
```

## Тестовые пользователи (вход только по логину)
- `admin` — администратор
- `manager1`, `manager2` — менеджеры
- `client01` … `client17` — авторизованные пользователи

Гость может просматривать каталог. Для корзины и оформления заказа войдите под логином клиента.
База `databases/mir_pryazhi.db` уже заполнена исходными данными: 31 модель, 93 цветовые позиции, 20 пользователей, 15 заказов и 30 строк состава. Остатки импортированы как указано в исходных материалах; повторного списания при импорте нет.
